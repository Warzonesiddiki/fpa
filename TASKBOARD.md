code + userMessage + retry flag; (c) money is Rust `i64`/`rust_decimal` (no `money:ast`

tests; (f) a11y/axe 0; (g) perf budget; (h) docs synced; (i) **real DB/persistence** — no mock in
the product path (B18-3).
